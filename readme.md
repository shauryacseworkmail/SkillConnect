# Kaam Ho Jayega

A landing page for **Kaam Ho Jayega**, a platform connecting customers with trusted local professionals (plumbers, electricians, mechanics, carpenters, and more) for everyday jobs.

## Project Structure

```
├── index.html      # Page markup
├── style.css       # Styles
└── script.js       # Interactivity
```

## Features

- **Sticky navbar** with a responsive mobile drawer menu
- **Hero section** with a service + location search form
- **Popular services grid** (Plumber, Electrician, Mechanic, Carpenter, Painter, AC Repair, Cleaner, Appliance Repair)
- **Footer** with sitemap, social links, and legal info
- Fully responsive layout (tablet and mobile breakpoints)
- Inline SVG icon sprite (no external icon library needed)

## Getting Started

1. Clone or download the project files.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Open `index.html` in a browser — no build step or server required.

## Tech Stack

- HTML5
- CSS3 (custom properties, CSS Grid & Flexbox)
- Vanilla JavaScript (no frameworks or dependencies)
- Fonts: [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts

## Notes

The navbar currently links to a few sections (`#professionals`, `#how`, `#pro`, `#about`) that are placeholders for future page sections — only the **Home** and **Services** sections are built out so far. As those sections are added to `index.html`, matching styles should be added to `style.css`.
